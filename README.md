# 🎨 Freeline (Work in Progress)

A 2D cozy mobile game developed in Unity 6 where players step into the shoes of a freelance artist creating a webtoon series. This project focuses on mobile-first UI interactions, resource economy, and progressive gameplay systems.

*Currently in active development. Core gameplay loops, interactive UI panels, and foundational systems are implemented. Preparing for iOS and Android release.*

## 🚀 Core Systems & Architecture

*   **Gameplay & Progression:** Core mechanics centered around drawing routines, managing resources, and progressing the webtoon series.
*   **Economy & Shop System:** A fully functional in-game currency system allowing players to purchase items, upgrades, and room decorations.
*   **Interactive UI/UX:** Mobile-oriented, responsive user interface with animated panels, dynamic buttons, and clear player feedback loops.
*   **Save & Data Management:** Persistent player data architecture managing economy, inventory, and room states.
*   **Clean Code Practices:** Utilizing C# object-oriented principles and event-driven architecture to decouple UI from gameplay logic, ensuring a maintainable codebase.
